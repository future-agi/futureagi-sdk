## client.experiments

### experiments.create

Create and start an experiment. The new experiment's id is returned inside the `result` message as `experiment_id=\<uuid>`; pass it to get_experiment to follow the run.

<ApiEndpoint method="POST" path="/model-hub/experiments/v2/" />

**MCP tool**: `create_experiment`

<CodeGroup>

```python Python
result = client.experiments.create(
    name="your-name",
    dataset_id="your-dataset-id",
    prompt_config=[],
    user_eval_metrics=[],
)
```

```typescript TypeScript
const result = await client.experiments.create({
  name: "your-name",
  dataset_id: "your-dataset-id",
  prompt_config: [],
  user_eval_metrics: [],
});
```

</CodeGroup>

### experiments.list

<ApiEndpoint method="GET" path="/model-hub/experiments/v2/list/" />

**Paginated**: returns a pager ([how pagination works](/docs/sdk/reference#pagination)) · **MCP tool**: `list_experiments`

<CodeGroup>

```python Python

    print(item)
```

```typescript TypeScript

}
```
