## client.alerts.logs

TypeScript: `client.alerts.logs`.

### alerts.logs.list

List alerts that have fired in numbered pages. Use this to find out what the platform has already flagged before digging into traces or error clusters.

<ApiEndpoint method="GET" path="/tracer/user-alert-logs/" />

**Paginated**: returns a pager ([how pagination works](/docs/sdk/reference#pagination)) · **MCP tool**: `list_fired_alerts`

```python Python
for item in client.alerts.logs.list():
    print(item)
```

## client.alerts.rules

TypeScript: `client.alerts.rules`.

### alerts.rules.list

List the configured alert monitors - what each one watches, its threshold and its project. Pair with list_fired_alerts to explain why an alert fired, or to see that no monitor covers a condition the user expected to be caught.

<ApiEndpoint method="GET" path="/tracer/user-alerts/list_monitors/" />

**MCP tool**: `list_alert_rules`

<CodeGroup>

```python Python
result = client.alerts.rules.list()
```
