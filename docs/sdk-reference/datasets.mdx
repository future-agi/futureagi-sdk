### datasets.cells.update

Set the value of a single dataset cell. Use this to correct one value; add_dataset_rows only appends and cannot edit an existing row. Pass new_value explicitly; omission is rejected. To clear a cell deliberately, pass None in Python or null in TypeScript; an explicit empty string also clears the cell.

<ApiEndpoint method="POST" path="/model-hub/develops/{dataset_id}/update_cell_value/" />

**MCP tool**: `update_dataset_cell`

<CodeGroup>

```python Python
result = client.datasets.cells.update(
    "your-dataset-id",
    row_id="your-row-id",
    column_id="your-column-id",
    new_value="your-new-value",
)
```

```typescript TypeScript
const result = await client.datasets.cells.update("your-dataset-id", {
  row_id: "your-row-id",
  column_id: "your-column-id",
  new_value: "your-new-value",
});
```

</CodeGroup>

#### Clear a cell deliberately

The API clears a cell when `new_value` is omitted, `null`, or `""`. To prevent accidental clearing, these SDK methods reject an omitted replacement (Python `NOT_GIVEN` or TypeScript `undefined`), including body overrides. Use Python `None` or TypeScript `null` explicitly as below; an explicit empty string also clears the cell.

<CodeGroup>

```python Python
result = client.datasets.cells.update(
    "your-dataset-id",
    row_id="your-row-id",
    column_id="your-column-id",
    new_value=None,
)
```

```typescript TypeScript
const result = await client.datasets.cells.update("your-dataset-id", {
  row_id: "your-row-id",
  column_id: "your-column-id",
  new_value: null,
});
```

</CodeGroup>
