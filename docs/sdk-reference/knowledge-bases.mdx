### knowledge_bases.list

List knowledge bases (the RAG stores with an embedding model and a chunk size) in the current workspace. Knowledge bases built from uploaded files are a separate store, see file_knowledge_bases.

<ApiEndpoint method="GET" path="/model-hub/kb/" />

**Paginated**: returns a pager ([how pagination works](/docs/sdk/reference#pagination)) · **MCP tool**: `list_knowledge_bases`

<CodeGroup>

```python Python
for item in client.knowledge_bases.list():
    print(item)
```

```typescript TypeScript
for await (const item of client.knowledgeBases.list()) {
  console.log(item);
}
```

</CodeGroup>
